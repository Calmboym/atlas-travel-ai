# Purpose

This document defines the visual language for icons, illustrations, photography, 3D assets, AI-generated imagery, and decorative graphics.

Every visual asset must reinforce the platform's core identity:

A trustworthy, calm, intelligent travel companion.

Visuals should communicate clarity, confidence, and exploration—not marketing hype or visual noise.

---

# Visual Identity Principles

Every visual asset should be:

• Calm

• Elegant

• Modern

• Human

• Minimal

• High quality

• Functional

Visual decoration must never compete with content.

---

# Design Philosophy

The interface is content-first.

Visual assets support understanding.

They never distract from the user's task.

---

# Icon System

Approved style:

Outlined icons with subtle rounded geometry.

Characteristics:

• Consistent stroke weight

• Simple silhouettes

• Pixel-aligned

• Minimal detail

• High readability

Avoid:

Filled icon sets mixed with outline sets.

Highly decorative icons.

Realistic icons.

Skeuomorphic icons.

---

# Icon Consistency

Every icon must share:

Stroke width

Corner radius

Perspective

Visual weight

Alignment

Icons from different design systems must not be mixed.

---

# Icon Sizes

Supported sizes:

16px

20px

24px

32px

48px

Preferred UI size:

20–24px

---

# Icon Colors

Default:

Current text color

Interactive:

Brand Primary

Disabled:

Neutral Gray

Error:

Semantic Red

Warning:

Semantic Amber

Success:

Semantic Green

Never rely on color alone to communicate meaning.

---

# Icon Usage

Icons support labels.

Icons rarely replace labels.

Navigation icons always include text on first exposure.

# Illustrations

Illustrations should feel:

Warm

Modern

Timeless

Friendly

Elegant

Avoid cartoon styles.

Avoid exaggerated facial expressions.

Avoid childish proportions.

---

# Illustration Style

Preferred:

Flat + subtle depth

Soft gradients

Rounded geometry

Minimal textures

Limited visual complexity

---

# Human Representation

Illustrations should represent diverse travelers.

Avoid stereotypes.

Avoid exaggerated emotions.

Use inclusive representation across:

Age

Gender

Ethnicity

Ability

Family structures

Travel styles

---

# Destination Artwork

Destination illustrations should emphasize:

Landscape

Architecture

Nature

Culture

Landmarks

Avoid excessive crowds.

Avoid promotional compositions.

---

# Photography

Photography should be:

Authentic

Natural

High resolution

Emotionally calm

Avoid:

Over-saturated colors

Heavy filters

Stock-photo appearance

Artificial poses

Overly dramatic editing

---

# AI-Generated Images

AI-generated imagery is permitted when:

Clearly beneficial

High quality

Factually appropriate

Consistent with brand style

AI imagery must never misrepresent reality.

If visual accuracy is uncertain, prefer photography.

---

# Image Cropping

Preserve subject.

Avoid cutting:

Faces

Landmarks

Primary objects

Support responsive crops.

---

# Empty State Illustrations

Purpose:

Reduce frustration.

Encourage next action.

Never feel childish.

Examples:

Compass

Suitcase

Map

Clouds

Notebook

Travel route

Minimal destination silhouette

---

# Onboarding Illustrations

Illustrations explain concepts.

They do not decorate.

Maximum:

One illustration per onboarding screen.

---

# AI Visual Language

The AI assistant is represented visually through subtle abstract elements.

Avoid:

Robot heads

Android mascots

Human avatars

Talking robots

Sci-fi faces

Preferred concepts:

Light

Constellation

Path

Compass

Connection

Abstract orbit

Travel route

---

# 3D Philosophy

Three.js is used only where it adds meaningful value.

Never as decoration throughout the application.

Primary usage:

Landing page

Marketing storytelling

Special promotional sections

---

# Landing Page 3D

Allowed scenes:

Airplane flight path

Rotating globe

Floating destination markers

Cloud layers

Travel route animation

Subtle landmark transitions

Forbidden:

Heavy particle systems

Large physics simulations

Complex interactive games

Long intro animations

---

# 3D Performance

3D assets must:

Load progressively

Pause when off-screen

Respect reduced-motion settings

Automatically disable on low-end devices

Never delay First Contentful Paint.

---

# Motion + Illustration

Illustrations may include subtle motion.

Examples:

Cloud drift

Airplane movement

Compass rotation

Map path drawing

Motion must remain secondary.

---

# Lottie Animations

Permitted for:

Empty states

Success states

Onboarding

Loading indicators

Avoid excessive looping.

---

# Emoji Usage

Emoji usage is minimal.

Allowed:

Occasional onboarding

Celebratory confirmations

Seasonal campaigns

Not allowed:

Navigation

Professional dashboards

Critical workflows

Error messages

---

# Background Graphics

Background graphics should be subtle.

Maximum opacity:

10%

Never reduce readability.

---

# Texture

Use minimal texture.

Flat surfaces are preferred.

Noise effects should be extremely subtle.

---

# Maps

Maps prioritize clarity.

Use:

Simple styling

Reduced visual clutter

Accessible color contrast

Destination pins consistent with design system.

---

# Weather Icons

Use a consistent weather icon family.

Avoid mixing filled and outlined weather icons.

---

# Flags

Avoid using flags to represent languages.

Use language names instead.

Example:

English

Deutsch

فارسی

Español

Not national flags.

# Optimization

All assets must be optimized before deployment.

No unused metadata.

No unnecessary resolution.

No oversized textures.

---

# Licensing

Only use assets with verified commercial licenses.

Maintain attribution records where required.

Never include unlicensed third-party assets.

---

# Accessibility

Every meaningful image requires descriptive alt text.

Decorative graphics:

Empty alt attribute.

Icons must never replace accessible labels.
