# AI Travel Platform

# PSYCHOLOGY GUIDELINES

Version: 1.0

Status:
LOCKED

This document defines the cognitive and behavioral psychology principles that govern every interaction in the platform.

No UI decision may violate these principles.

------------------------------------------------------------
1. UX PHILOSOPHY
------------------------------------------------------------

The product should never make users think unnecessarily.

Users should feel:

"I know exactly what to do."

Every interaction should reduce uncertainty.

Every page should reduce stress.

The platform guides.

The user decides.

------------------------------------------------------------
2. COGNITIVE LOAD THEORY
------------------------------------------------------------

Reduce mental effort.

Rules

• One primary action per screen.

• Avoid unnecessary information.

• Break large tasks into steps.

• Group related information.

• Hide advanced features until needed.

Never overwhelm users.

------------------------------------------------------------
3. HICK'S LAW
------------------------------------------------------------

More choices increase decision time.

Rules

Never present too many actions.

Primary CTA:

1

Secondary CTA:

Maximum 2

Avoid long menus.

AI should narrow choices.

Never display 50 hotels at once.

Show curated recommendations first.

------------------------------------------------------------
4. FITTS'S LAW
------------------------------------------------------------

Frequently used actions must be easier to reach.

Examples

Chat Button

Navigation

Search

Continue Trip

Profile

Mobile

Bottom navigation is mandatory.

Floating AI remains reachable.

------------------------------------------------------------
5. JAKOB'S LAW
------------------------------------------------------------

Users expect familiar behavior.

Rules

Navigation behaves like modern web apps.

Forms behave like modern forms.

Buttons look clickable.

Links look like links.

Never reinvent basic UI.

Innovation belongs in AI.

Not in navigation.

------------------------------------------------------------
6. MILLER'S LAW
------------------------------------------------------------

Working memory is limited.

Rules

Chunk information.

Use cards.

Use sections.

Use progressive disclosure.

Never display everything at once.

------------------------------------------------------------
7. GESTALT PRINCIPLES
------------------------------------------------------------

Visual grouping must follow

Proximity

Similarity

Continuity

Closure

Common Region

Common Fate

Spacing communicates relationships.

Borders are secondary.

------------------------------------------------------------
8. PROGRESSIVE DISCLOSURE
------------------------------------------------------------

Show only what users need now.

Advanced options appear later.

Examples

Budget filters

Accessibility

Travel preferences

Packing

AI explains only when necessary.

------------------------------------------------------------
9. PEAK-END RULE
------------------------------------------------------------

Users remember

The best moment.

The last moment.

Therefore

Landing

Trip Completion

Post Travel

must feel exceptional.

------------------------------------------------------------
10. GOAL GRADIENT EFFECT
------------------------------------------------------------

Visible progress motivates completion.

Examples

Profile Completion

Trip Progress

Booking Progress

Planning Progress

Use progress indicators.

------------------------------------------------------------
11. ZEIGARNIK EFFECT
------------------------------------------------------------

People remember unfinished tasks.

Use carefully.

Examples

Resume Trip

Continue Planning

Incomplete Profile

Never manipulate users.

------------------------------------------------------------
12. LOSS AVERSION
------------------------------------------------------------

Avoid creating anxiety.

Never fake urgency.

Never show fake scarcity.

Only display real travel risks.

------------------------------------------------------------
13. DECISION FATIGUE
------------------------------------------------------------

AI reduces choices.

Instead of

100 hotels

Recommend

Top 5

Explain why.

------------------------------------------------------------
14. TRUST SIGNALS
------------------------------------------------------------

Trust is the most valuable asset.

Always explain recommendations.

Display

Sources

Confidence

Reasoning

Freshness

Users must understand:

Why this recommendation exists.

------------------------------------------------------------
15. EXPLAINABLE AI
------------------------------------------------------------

Every recommendation answers

Why this?

Why now?

Why for me?

Never behave like a black box.

------------------------------------------------------------
16. ERROR PSYCHOLOGY
------------------------------------------------------------

Errors should reduce stress.

Explain

What happened.

What users can do.

Offer recovery.

Never blame users.

------------------------------------------------------------
17. EMPTY STATES
------------------------------------------------------------

Every empty state teaches.

Examples

No Trips

↓

Start Planning

No Memories

↓

Explain benefits

No Notifications

↓

Explain future alerts

------------------------------------------------------------
18. WAITING PSYCHOLOGY
------------------------------------------------------------

Waiting feels shorter when users understand progress.

Streaming preferred.

Skeleton preferred.

Never blank screen.

------------------------------------------------------------
19. FEEDBACK PRINCIPLE
------------------------------------------------------------

Every interaction gives feedback.

Click

Hover

Loading

Saved

Deleted

Copied

Shared

No silent actions.

------------------------------------------------------------
20. RECOGNITION OVER RECALL
------------------------------------------------------------

Users recognize faster than remember.

Show

Recent Trips

Recent Searches

Suggestions

History

Recently Used

------------------------------------------------------------
21. PERSONALIZATION
------------------------------------------------------------

The platform becomes smarter.

Never becomes creepy.

Always allow editing.

Always allow deleting memories.

Users remain in control.

------------------------------------------------------------
22. AI CONVERSATION
------------------------------------------------------------

AI asks useful questions.

Not too many.

Not too few.

Prefer conversation.

Avoid forms when AI can infer.

------------------------------------------------------------
23. SCROLL BEHAVIOR
------------------------------------------------------------

Scrolling should feel rewarding.

Landing may use storytelling.

Every section answers a question.

Never create endless decorative scrolling.

------------------------------------------------------------
24. MOTION PSYCHOLOGY
------------------------------------------------------------

Motion guides attention.

Motion communicates hierarchy.

Motion confirms actions.

Motion never distracts.

------------------------------------------------------------
25. COLOR PSYCHOLOGY
------------------------------------------------------------

Blue

Trust

Teal

Discovery

Green

Safety

Amber

Attention

Red

Critical issues

Color communicates meaning.

Never decoration.

------------------------------------------------------------
26. TYPOGRAPHY PSYCHOLOGY
------------------------------------------------------------

Readable.

Comfortable.

Predictable.

Large headings reduce uncertainty.

Body text optimized for scanning.

------------------------------------------------------------
27. NAVIGATION CONFIDENCE
------------------------------------------------------------

Users always know

Where they are.

Where they came from.

Where to go next.

------------------------------------------------------------
28. MICROCOPY
------------------------------------------------------------

Every sentence must help.

Avoid technical language.

Avoid marketing buzzwords.

Write naturally.

Examples

Good

Let's plan your trip.

Bad

Experience the revolutionary AI travel ecosystem.

------------------------------------------------------------
29. POST TRAVEL EXPERIENCE
------------------------------------------------------------

The relationship does not end.

After every trip

Ask

What went well?

What went wrong?

What should we remember?

Learning creates loyalty.

------------------------------------------------------------
30. SUCCESS METRIC
------------------------------------------------------------

Users should leave every session feeling

Confident

Supported

Less stressed

Better informed

Understood

If these emotions are missing,

The UX has failed.

------------------------------------------------------------

END OF DOCUMENT
