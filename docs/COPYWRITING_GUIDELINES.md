# Purpose

This document defines the writing standards for every user-facing piece of text in the AI Travel Platform.

It ensures that every interface, AI response, notification, onboarding step, email, and system message speaks with one consistent voice.

These rules are mandatory for both human-written and AI-generated content.

---

# Core Principle

Every sentence must accomplish at least one objective:

• Inform

• Guide

• Reassure

• Clarify

• Help the user make a decision

If a sentence serves none of these purposes, remove it.

---

# Writing Philosophy

The platform writes like a calm travel expert.

Never like:

• a salesperson

• an influencer

• a marketing website

• a technical manual

• a search engine

The platform communicates with confidence, not excitement.

---

# Sentence Length

Preferred:

8–18 words.

Long explanations should be broken into small paragraphs.

Avoid walls of text.

---

# Paragraph Length

Maximum:

4 lines on desktop.

Maximum:

3 lines on mobile.

If longer, split it.

---

# Active Voice

Always prefer active voice.

Good:

"We found three great options."

Bad:

"Three options have been found."

---

# Direct Language

Speak directly to the user.

Use:

You

Your trip

Your itinerary

Avoid:

The user

Customers

Clients

---

# Simplicity

Prefer:

Start planning

instead of

Commence itinerary generation

Prefer:

Hotel

instead of

Accommodation establishment

---

# Clarity Over Cleverness

Never sacrifice understanding for creativity.

Avoid clever jokes.

Avoid wordplay.

Avoid travel puns.

---

# Consistency

Always use the same terminology.

Examples:

Trip

Destination

Budget

Traveler

Accommodation

Itinerary

Do not alternate between multiple synonyms.

---

# Button Labels

Buttons must begin with verbs whenever possible.

Examples:

Start Planning

Continue

Save Trip

Compare

Export

Ask AI

Retry

Cancel

Edit

Delete

Share

Avoid vague labels:

Go

Next

Submit

OK

---

# Navigation Labels

Navigation should use nouns.

Examples:

Trips

Explore

Hotels

Flights

Settings

Profile

Chat

Dashboard

---

# Empty State Copy

Structure:

What happened

Why it matters

What to do next

Example:

No saved trips yet.

Create your first itinerary to access it anytime.

Start Planning

---

# Success Messages

Keep them brief.

Examples:

Trip saved.

Profile updated.

Preferences saved.

Payment completed.

Download ready.

---

# Error Messages

Structure:

Problem

Reason (if known)

Recovery action

Example:

We couldn't connect to the server.

Please check your connection and try again.

Never use:

Unknown Error

Something went wrong

Error 500

---

# Confirmation Messages

Confirm user intent before destructive actions.

Example:

Delete this itinerary?

This action cannot be undone.

Buttons:

Delete

Cancel

---

# Loading Messages

Avoid generic:

Loading...

Prefer context.

Examples:

Finding destinations...

Building your itinerary...

Comparing flights...

Saving your trip...

---

# AI Response Structure

Recommended structure:

Direct answer

↓

Reasoning

↓

Supporting details

↓

Suggested next steps

↓

Optional related recommendations

---

# AI Language

The AI should:

Explain.

Compare.

Recommend.

Warn when necessary.

Never lecture.

Never dominate the conversation.

Never pretend certainty.

---

# AI Uncertainty

When information cannot be verified:

Say so clearly.

Example:

"I couldn't confirm the latest opening hours."

instead of guessing.

---

# Numbers

Always format consistently.

Examples:

3 days

€1,250

12 km

09:30

4.8 / 5

---

# Dates

Use localized formats.

Example:

English:

July 15, 2026

German:

15. Juli 2026

Persian:

۱۵ تیر ۱۴۰۵

---

# Currency

Always display currency symbol or code.

Examples:

€850

$1,200

AED 950

Never display numbers without units.

---

# Lists

Prefer bullet lists when presenting:

Recommendations

Features

Packing lists

Tips

Requirements

---

# Tooltips

Maximum:

20 words.

Tooltips explain.

They do not teach.

---

# Helper Text

Helper text should answer:

What is expected?

Examples:

Budget

Maximum amount you want to spend.

---

# Placeholder Text

Placeholder text gives examples.

Never replace labels.

Example:

Destination

Placeholder:

Tokyo, Japan

---

# Notifications

Maximum:

2 short sentences.

Avoid unnecessary details.

---

# Push Notifications

Respect user attention.

Examples:

Your itinerary is ready.

New price alert for your saved flight.

Avoid promotional messages.

---

# Emails

Emails should include:

Purpose

Context

Action

Support information

Footer

Avoid unnecessary marketing language.

---

# Onboarding Copy

One idea per screen.

Maximum:

40 words.

Users should never feel overwhelmed.

---

# CTA Writing Rules

Primary CTA:

Action-oriented.

Secondary CTA:

Lower pressure.

Example:

Primary:

Start Planning

Secondary:

Explore Destinations

---

# AI Suggestions

Phrase suggestions naturally.

Examples:

You may also enjoy...

Another option worth considering...

If you're traveling in autumn...

Avoid:

You MUST

You SHOULD

Best choice

Perfect destination

---

# Warnings

Warnings should remain calm.

Example:

Heavy rainfall is expected during this period.

Consider flexible travel dates.

Avoid dramatic wording.

---

# Humor

Use sparingly.

Never in:

Errors

Payments

Security

Medical information

Legal pages

---

# Accessibility Writing

Write for everyone.

Avoid complex vocabulary.

Avoid unexplained abbreviations.

If an abbreviation is necessary:

Write it once in full.

---

# Localization Rules

Every translation must preserve:

Meaning

Tone

Intent

Not literal wording.

---

# SEO Writing

Write for humans first.

Use headings logically.

Natural keyword usage only.

Avoid repetition.

---

# Forbidden Language

Never use:

Guaranteed

Perfect

Best in the world

Unlimited possibilities

Life-changing

100% accurate

Instantly

Magic

Revolutionary

Unless objectively verifiable.

---

# Brand Vocabulary

Preferred words:

Discover

Explore

Plan

Journey

Travel

Destination

Experience

Guide

Recommendations

Trip

Avoid:

Hack

Secret

Ultimate

Insane

Crazy

Mind-blowing

Copy is complete only if it is:

Clear

Useful

Brand-consistent

Human

Trustworthy
